Сучасний, швидкий та мінімалістичний веб-додаток для створення, перегляду та редагування ментальних карт (mind maps) у форматі **`.mm`** (сумісний із **FreeMind** та **Freeplane**). 

Додаток працює повністю на стороні клієнта у браузері: **жодного бекенду, жодного збирання (build-free)**, повна приватність ваших даних.

👉 **[Відкрити додаток (Live Demo)](https://<ТВІЙ_ЮЗЕРНЕЙМ>.github.io/<НАЗВА_РЕПОЗИТОРІЮ>/)**

---

## ✨ Основні можливості

- **Повна сумісність із `.mm`**: імпорт та експорт XML-структури FreeMind / Freeplane.
- **100% приватність (Client-Side)**: файли обробляються локально у вашому браузері і нікуди не завантажуються.
- **Швидке збереження (`Ctrl + S`)**: підтримка сучасного *File System Access API* для прямого збереження без зайвих завантажень файлів.
- **Drag & Drop**: просто перетягніть файл `.mm` із робочого столу у вікно браузера.
- **Автозбереження**: поточна карта автоматично кешується в `localStorage`, тож ви не втратите прогрес при випадковому оновленні вкладки.
- **Сучасний UI**: плаваюча панель із підтримкою темної та світлої теми (Dark / Light mode).
- **Зручне керування з клавіатури**: повноцінні гарячі клавіші для швидкого генерування ідей без відриву рук від клавіатури.

---

## ⌨️ Гарячі клавіші

| Дія | Клавіша |
| :--- | :--- |
| **Створити дочірній вузол (Child)** | <kbd>Tab</kbd> |
| **Створити сусідній вузол (Sibling)** | <kbd>Enter</kbd> |
| **Редагувати текст вузла** | <kbd>Space</kbd> або <kbd>F2</kbd> |
| **Видалити вибраний вузол** | <kbd>Delete</kbd> / <kbd>Backspace</kbd> |
| **Згорнути / розгорнути гілку** | <kbd>/</kbd> |
| **Швидке збереження карти (.mm)** | <kbd>Ctrl</kbd> + <kbd>S</kbd> *(або <kbd>Cmd</kbd> + <kbd>S</kbd>)* |

## 🛠 Стек технологій

- **HTML5 / CSS3 / Vanilla JavaScript** — чистий код без потреби в Node.js, Webpack або Vite.
- **[Mind-Elixir](https://github.com/ssshooter/mind-elixir-core)** — ядро та інтерактивна візуалізація карти.
- **[Lucide Icons](https://lucide.dev/)** — легкі векторні іконки інтерфейсу.
- **DOMParser & XMLSerializer** — нативний браузерний парсинг формату `.mm`.
